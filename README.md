 Busy Bees Gate Management System

A single webpage that replaces the paper-based gate duty system at Busy Bees Primary.

The Problem

Gate duty and incident reporting are managed on paper. This causes lost information, confusion about rotation, and no accountability.

The Solution

One webpage. No installation. Works on any phone or school computer.

- 2 teachers on duty per week (Monday to Friday)
- Fair rotation — no teacher repeats until everyone has had a turn
- Pairs arranged by nationality (internal only) so no one clashes
- Incident logging — date, time, description, action taken
- History of past incidents in one view
